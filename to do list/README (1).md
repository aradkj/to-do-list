# My Todo List

## 🇮🇷 فارسی

**My Todo List** یک برنامه ساده و سبک برای مدیریت کارهای روزانه است که برای ویندوز به‌صورت فایل اجرایی (`.exe`) ساخته شده است.

### ✨ امکانات

- ➕ اضافه کردن کارهای جدید
- ✅ علامت‌گذاری کارهای انجام‌شده
- 📝 مدیریت و مشاهده فهرست کارها
- 💾 ذخیره خودکار اطلاعات
- 🌙 رابط کاربری تیره و ساده
- 🖥️ قابل اجرا در ویندوز به‌صورت مستقل
- ⚡ طراحی ساده و سریع برای استفاده روزمره

### 📦 اجرا

برای اجرای برنامه کافی است فایل زیر را اجرا کنید:

```text
MyTodoList.exe
```

نیازی به اجرای Python یا نصب جداگانه محیط برنامه‌نویسی برای استفاده از نسخه اجرایی نیست.

### 🎯 هدف پروژه

هدف این پروژه ساخت یک **To-Do List ساده و کاربردی برای دسکتاپ** و همچنین تمرین فرایند ساخت، تست و انتشار یک برنامه قابل اجرا برای ویندوز است.

### 🛠️ وضعیت پروژه

پروژه در حال توسعه است و قابلیت‌های بیشتری می‌توانند در نسخه‌های آینده به آن اضافه شوند.

### 📌 پیشنهاد برای نسخه‌های آینده

- حذف کردن کارها
- ویرایش کارها
- فیلتر کردن کارهای انجام‌شده و انجام‌نشده
- تعیین اولویت برای کارها
- تعیین تاریخ و زمان
- جستجو بین کارها

# My Todo List

## 🇬🇧 English

**My Todo List** is a simple and lightweight desktop application for managing daily tasks. It is distributed as a standalone Windows executable (`.exe`).

### ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 📝 Manage and view your task list
- 💾 Automatic data saving
- 🌙 Simple dark user interface
- 🖥️ Standalone Windows executable
- ⚡ Simple and fast for everyday use

### 📦 How to Run

Simply run the following file:

```text
MyTodoList.exe
```

The executable version does not require Python or a separate programming environment to run.

### 🎯 Project Goal

The goal of this project is to create a **simple and practical desktop To-Do List application** while also practicing the process of building, testing, packaging, and releasing a Windows executable application.

### 🛠️ Project Status

The project is under development, and additional features may be added in future versions.

### 📌 Possible Future Features

- Delete tasks
- Edit tasks
- Filter completed and pending tasks
- Task priorities
- Due dates and times
- Task search
- Task categories
- Theme customization
- Backup and restore functionality
